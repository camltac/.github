# Camltac

Camltac is an OCaml plugin for Rocq that lets you write OCaml meta-programs and tactics directly inside Rocq scripts.

## Repositories

| Repository | Description |
| --- | --- |
| [Camltac](https://github.com/epfl-systemf/camltac) | The Camltac plugin: OCaml as a Tactic Language for the Rocq Prover. |
| [ppx_rocq](https://github.com/epfl-systemf/ppx_rocq) | PPX syntax extensions for quoting Rocq terms in OCaml. |
| [MLtac2](https://github.com/epfl-systemf/mltac2) | Ltac2 APIs for OCaml. |

## Getting started

See the [Camltac README](https://github.com/epfl-systemf/camltac) for installation instructions and a quickstart, or the [tour of Camltac](https://camltac.github.io/latest/tour) for an overview of its features.
